# Project NutriFast: Bio-Optimization Planner

## 📌 Project Overview
NutriFast is an AI-driven optimization tool designed to bridge the gap between biometric fasting schedules (specifically 18:6 cycles) and personalized, restrictive meal planning. 

## 🗺️ Project Charter
### 1. Purpose & Justification
Current market solutions function primarily as simple timers or generic calorie trackers. They fail to address the specific micro/macro-nutrient requirements needed to prevent energy crashes during extended fasting windows, particularly for users with strict dietary restrictions (e.g., avoiding high-fat staples like avocados or walnuts).

### 2. High-Level Objectives
* **Product Definition:** Deliver a fully articulated PRD, Figma wireframes, and system architecture design.
* **MVP Delivery:** Build and deploy a functioning MVP using simulated/integrated health data.
* **Validation:** Achieve a System Usability Scale (SUS) score of 75+ through user testing.
